# Prepare Your Exams — Admin Panel

A private teacher/admin panel for managing books, chapters, notes, MCQs, and
repeated exam questions. Built with Next.js, TypeScript, Tailwind CSS,
shadcn/ui, and Appwrite.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Environment variables

Appwrite credentials go in a local `.env.local` file (never committed — it's
already excluded by `.gitignore`). This file will be added once the Appwrite
project is set up.
